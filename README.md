# 赛博看板 / Saibo Kanban

一个给 DeepSeek Harness 用的**活看板**：AI 负责起草，人负责调整，每次改动都能回滚。

> 当前版本 0.6.0：左侧出现「看板」入口，中央面板有收件箱 / 看板 / 表格三视图；
> 七个工具（含回滚）；对话里每条 AI 回复都能一键加入这块全局看板。AI 与人权限对等，出错就回滚。

## 为什么做这个

- AI 写东西准确率 80–90%，会漏、会改口。所以每条改动都留修订，**错了一键回滚**。
- 人没有填表的意愿，但有改和删的意愿。页面以表格为主界面，点单元格就能改。
- Excel 的问题不是「表格」，是没有行身份、字段约束和变更历史。看板就是一张**有状态的智能表格**。

## 设计

- **收件箱**：最近变更的条目，用来快速扫一眼。
- **看板**：按状态分列，拖拽换列。
- **表格**：主界面，点标题直接改，类型/状态/范围用下拉。
- **详情抽屉**：全字段 + 修订历史，每一版都有「回滚」。
- **从对话加入**：每条 AI 回复旁有「＋ 看板」，一点就落板，范围 / 类型 / 状态由 AI 在消息里给出。

数据模型：条目带稳定 ID，每次写入都是**新修订**（字段级 diff、作者、来源），不是覆盖。
权限对等：AI 可以标完成；人通过页面做同样的事。防跑偏靠状态机校验、必填校验、乐观锁（带错修订号就拒绝）和回滚。

**npm**

```bash
dsh plugin --profile web add saibo-kanban
```

**GitHub 源码**

```bash
dsh plugin --profile web add github:QuChen-D/saibo_kanban
```

存放在 `$DSH_HOME/saibo_kanban/records.jsonl`（只追加），可用 `config.dataDir` 改。
卸载插件不删除数据。

## 怎么用

**对话**

```
记一条：把导入改成列映射 + 预览，范围 导入
看看板简报
找一下关于表单的条目
```

**页面**：左侧「看板」图标 → 收件箱 / 看板 / 表格。

**从对话加入看板（所有会话都能用）**

看板是全局的：任何会话里的 AI 回复下面都有「＋ 看板」。
AI 在回复末尾写一个 `board` 代码块来声明要落板的内容，一行一条，最多 3 条：

```board
已完成｜任务｜G5 前端｜修好打印图标
待办｜决策｜存储｜看板改用 SQLite
```

字段顺序是 `状态｜类型｜范围｜标题`，状态写 `待规划/待办/进行中/待验收/已完成/受阻`，
类型写 `任务/决策/踩坑/设计`，范围留空就写两个竖线连着（如 `进行中｜任务｜｜标题`）。
点「＋ 看板」时按这些值**直接写入**，不弹窗、不二次确认；沟通完即完成的，加进来就是「已完成」。
没有代码块时退化为「首行当标题、待办、任务」。同范围同标题已有条目时不再重复建：AI 给的状态和看板不一致，
就直接把那条的状态改掉（同样记修订，可回滚），一致才算「已在看板」。
点到只有工具调用、没有文字的步骤时，自动落到同轮最后一条有内容的回复。
不想要这条约定时，配置里 `captureHint: false`，按钮仍然可用。

**CLI**

```bash
node bin/board.mjs list
node bin/board.mjs add "标题" --kind decision --scope 存储
node bin/board.mjs show <id>
node bin/board.mjs brief
```

**页面导入（推荐）**

看板面板 → 右上角「导入 xlsx」→ 选择文件 → 看预览（主表 / 滚动项 / 节点说明各多少条）→ 确认导入。

**命令行导入**

```bash
node bin/import.mjs --xlsx "C:\path\开发任务管理看板.xlsx" --dry-run
node bin/import.mjs --xlsx "C:\path\开发任务管理看板.xlsx"
```

主表进归档（历史台账），长期滚动项进活跃列，节点说明合成一条 design 资产；重复条目按「范围 + 标题」跳过。

## 工具

| 工具 | 作用 |
|---|---|
| `board_brief` | 读简报：按状态列出全部条目 |
| `board_record` | 写入一条新条目 |
| `board_update` | 按字段改一条，必须带 `expectedRev` |
| `board_supersede` | 用新条目取代旧条目，旧条目保留并指向新条目 |
| `board_merge` | 合并两条以上，来源归档并指向新条目 |
| `board_rollback` | 回滚到任意修订，回滚本身也记一条修订 |
| `board_search` | 按关键词 / 状态 / 类型 / 范围检索 |
