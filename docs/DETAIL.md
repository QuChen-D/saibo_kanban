# 赛博看板

AI 与人共用的活看板。当前版本 **0.2.0**：六个工具可用，界面在 0.3.0 接入。

## 设计

- **收件箱**：AI 起草的条目先落到这里，人只做四件事——接受、退回、合并、删除。
- **看板**：按状态分列，拖拽换列即改状态。
- **表格**：主界面。点单元格就地改字段，不需要打开表单。
- **详情抽屉**：全字段、修订历史、来源追溯。
- **确认状态**：AI 写入默认「待确认」，人点过才变「已确认」；未确认的条目不进入任何下游摘要。

## 修订，不覆盖

每次修改生成一条新修订，记录字段级「改前 → 改后」、修改者和时间。任何一次 AI 改动都能看到，也能回滚。
AI 只能按字段 patch，不能整条覆盖、不能标记完成、不能物理删除。

## 数据位置

`$DSH_HOME/saibo_kanban/records.jsonl`（只追加，可用 `config.dataDir` 修改）。卸载插件不删除数据。

## 使用

安装后在任意会话里让 agent 用 `board_record` 记一条，用 `board_brief` 取简报；
人的确认与归档用 CLI：`node bin/board.mjs inbox` 查看，`accept <id>` 接受。
0.3.0 起看板页面会出现在 DSH 中（表格 / 看板 / 收件箱三视图）。
